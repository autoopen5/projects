## Порядок действий: что делать после покупки

1. **День 1** (1 час): Настроить RPi Zero 2W — установить Raspberry Pi OS Lite
2. **День 2** (2 часа): Подключить DHT22, написать скрипт сбора данных
3. **День 3** (1 час): Настроить Telegram-бот, команда `/status`
4. **День 4** (1 час): Подключить реле к помпе, команда `/water`
5. **День 7** (2 часа): Подключить камеру, команда `/photo`
6. **Неделя 3-4**: Добавить анализ фото через Claude API

**Итого до рабочей умной фермы: 2-3 недели по 1-2 часа вечером**
