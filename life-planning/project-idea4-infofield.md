# Идея 4 — Аналитика информационного поля: детальная проработка

---

## Проблема — почему это важно

Ефимов говорит: третий приоритет управления — это **хронологическая и фактологическая информация**. Кто формирует картину мира у человека — тот им и управляет. Не через приказы, а через то, что человек считает само собой разумеющимся.

**Что происходит с обычным человеком сегодня:**
- Читает 20–30 новостей в день
- Не может отличить факт от интерпретации — они смешаны в одном тексте
- Не знает кто стоит за изданием и какой у него интерес
- Формирует мнение не из реальности, а из чужой подачи реальности
- Принимает решения (голосование, покупки, отношение к событиям) на основе управляемой картины

**Результат:** человек думает, что у него есть мнение. На самом деле — у него есть мнение, которое ему дали.

Инструмент, который это показывает — это буквально **вакцина от информационного управления**.

---

## Что делает продукт — конкретно

Пользователь вводит тему: «рост цен на продукты», «новый закон об X», «ситуация в Y» — любая.

### Шаг 1: Сбор
Система собирает всё что написано по теме за нужный период из разных источников: федеральные СМИ, региональные, Telegram-каналы, иностранные источники на русском.

### Шаг 2: Разделение факт / интерпретация
ИИ анализирует каждый материал и разделяет:

```
ФАКТ (верифицируемо):
  «Индекс потребительских цен вырос на 8.3% по данным Росстата за апрель»
  «Министерство опубликовало постановление №XXX от 15.04»

ИНТЕРПРЕТАЦИЯ (чья-то оценка):
  «Власти не справляются с инфляцией»
  «Это временные трудности, ситуация стабилизируется»
  «Западные санкции привели к...»
  «Неэффективная политика ЦБ...»
```

### Шаг 3: Карта источников
Кто что говорит, и что известно об этом источнике:

```
РБК: публикует факт + либеральную интерпретацию
RT: публикует тот же факт + провластную интерпретацию  
Незалежный канал в TG: только интерпретация, факты не приводит
Региональная газета: перепечатка федерального без своей позиции
```

### Шаг 4: Паттерны и аномалии
- Какие нарративы синхронно появились сразу в 10 источниках (признак управляемого вброса)
- Какие факты никто не упоминает хотя они есть
- Где разные стороны подают один факт принципиально по-разному

### Шаг 5: Личный дайджест
Пользователь настраивает: какие темы важны, какой уровень детализации, как часто. Получает утреннюю выжимку: «Сегодня важное — вот факты, вот кто и как их интерпретирует».

## Кому это нужно и почему заплатят

### Частные пользователи
- Люди которые хотят понимать реальность, а не потреблять новости
- Инвесторы — им критично понимать что реально происходит с экономикой
- Предприниматели — принимают решения на основе среды
- **Готовы платить:** 199–399 руб/мес, аналогично подписке на качественное медиа

### B2B — аналитические отделы
- Корпорации с PR-отделами: мониторинг как их упоминают и в каком контексте
- Политические структуры: анализ информационного поля
- Исследовательские организации
- **Готовы платить:** 10–50 тыс/мес за команду

### Образовательный сегмент
- Школы медиаграмотности
- Журналисты которые хотят работать честно
- **Формат:** лицензия на использование в обучении

## Связь с концепцией Ефимова

В КОБ шесть приоритетов управления. Первые три — самые мощные, потому что незаметные:

1. **Мировоззренческий** — какая картина мира у человека
2. **Хронологический** — какую историю он знает
3. **Фактологический** — какие факты он считает реальными

Этот продукт работает именно на третьем уровне — **показывает человеку как формируется его картина «фактов»**. Когда человек видит механику — он перестаёт быть объектом управления через этот канал.

Ефимов говорит: «Управляй по приоритетам» — значит сначала формируй мировоззрение, потом всё остальное выстраивается само. Этот инструмент помогает людям **защититься** от чужого управления их мировоззрением.

Это не инструмент пропаганды — это инструмент **осознанности**. Продукт не говорит «вот правда» — он говорит «вот как разные стороны подают одно и то же, смотри сам».

## Как это можно построить технически (твой стек)

```python
# Общая архитектура
1. Парсер источников (Python + Scrapy/requests)
   → Telegram API, RSS-ленты СМИ, веб-скрапинг

2. Классификатор факт/мнение (Claude API / fine-tuned LLM)
   → На каждый абзац: fact / opinion / mixed
   → Извлечение: кто, что, источник данных

3. Граф источников (NetworkX + визуализация)
   → Связи между изданиями, цитирования, общие нарративы

4. Детектор синхронных вбросов
   → Если N источников публикуют похожее в течение M часов — флаг

5. Интерфейс (Telegram-бот + простой веб)
   → Запрос темы → результат через 30 сек
   → Персональный дайджест по расписанию

6. Хранилище (ClickHouse — у тебя уже есть)
   → Вся история, быстрая аналитика по времени
```

**Время до MVP:** 2–3 месяца при работе в свободное время.  
**Что делать первые 2 недели:** парсер 5–10 источников + простейший факт/мнение классификатор + Telegram-бот с запросом темы.

## Связь с Идеей 3 (управленческий ИИ)

Идеи 3 и 4 хорошо дополняют друг друга:

- **Идея 4** помогает человеку **видеть реальность** (не управляться через информацию)
- **Идея 3** помогает человеку **действовать правильно** (управлять по полной функции)

Это фактически два модуля одной платформы:
> «Сначала разберись что реально происходит (Идея 4), потом прими правильное управленческое решение (Идея 3)»

Можно начать с одного, потом объединить.
