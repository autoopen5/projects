# Путешествия вокруг событий: покер, спорт, жизнь

> Событие — лучший повод для поездки. Ты едешь не «просто в Барселону», а на EPT Barcelona. Сразу есть якорь, расписание и компания. Вокруг события строится всё остальное.

## Покер — мировые серии и где играть

### EPT (European Poker Tour, PokerStars)
Главная покерная серия Европы. Несколько стопов в год, каждый — крупный фестиваль на 1–2 недели.

| Стоп | Город | Обычно когда | Совместить с |
|------|-------|-------------|--------------|
| **EPT Barcelona** | Барселона, Испания | Август | Пляж, Гауди, Камбрилс рядом |
| **EPT Prague** | Прага, Чехия | Декабрь | Рождественские ярмарки, Вена рядом |
| **EPT Monte Carlo** | Монако | Апрель–Май | Гран-при Монако (F1!), Лазурный берег |
| **EPT Dublin** | Дублин, Ирландия | Октябрь | Ирландские пабы, побережье |
| **EPT Malta** | Мальта | Ноябрь | Тепло, история, Средиземноморье |

### King's Casino (Rozvadov, Чехия)
Крупнейшее казино Европы, постоянно проходят крупные серии (WSOPE, Merit, и др.).
- Роздавов — маленький городок на границе с Германией
- Час от Праги, 2 часа от Мюнхена
- Удобно совмещать с Прагой или поездкой в Германию

### WSOP — World Series of Poker
- **Лас-Вегас**, июнь–июль (6 недель)
- Главное покерное событие в мире
- Даже если не играешь в мейн эвент — атмосфера уникальная
- Совместить: Большой Каньон (4 ч от Вегаса), Лос-Анджелес, Национальные парки США
- Бюджет поездки: серьёзный, но опыт — уровень жизни

## Карта: где всё это пересекается

### Монако / Лазурный берег — идеальная комбо-точка
```
EPT Monte Carlo (апрель/май)
  + Гран-при Монако F1 (май)
  + Канны, Ницца, Антиб
  = одна неделя, три события, один из красивейших маршрутов мира
```

### Барселона — летний вариант
```
EPT Barcelona (август)
  + пляж (рядом Коста-Брава, Коста-Дорада)
  + Гауди, Готический квартал
  = 10–14 дней, покер + отдых
```

### Прага — зимний вариант
```
EPT Prague (декабрь)
  + Рождественские ярмарки Праги и Вены
  + King's Casino (рядом)
  = неделя, можно с семьёй или без
```

### Сингапур — азиатский вариант
```
Гран-при Сингапура F1 (сентябрь, ночная гонка)
  + Малайзия или Бали рядом
  + Покер в Marina Bay Sands
  = 10–14 дней Азия
```

## Принцип планирования вокруг событий

1. **Выбрать 1–2 якорных события** на год (покер-турнир, спортивное событие)
2. **Построить поездку вокруг них** — прилететь за 2–3 дня до, улететь через 2–3 дня после
3. **Заполнить дни вокруг** — город, природа, рестораны
4. **Семейный vs личный формат** — часть поездок с семьёй, часть (покер/спорт) — отдельно
