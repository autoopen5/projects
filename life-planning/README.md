## Еженедельный ритм (15 минут в воскресенье)

1. Открыть этот файл
2. Пройтись по каждому направлению — что сделано, что сдвинулось
3. Обновить «Текущий фокус» в нужных файлах
4. Записать одну главную задачу на следующую неделю по каждому направлению

## Принципы системы

- **Один фокус на направление** — не больше одной активной цели одновременно
- **Метрики, не намерения** — если нельзя измерить, переформулировать
- **Маленький шаг лучше большого плана** — конкретное действие на эту неделю важнее красивых целей на год
- **Пересмотр раз в квартал** — в конце каждого квартала обновить цели и направления
