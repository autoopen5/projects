# Робот-помощник для детей

> Физический робот с доступом к Claude AI. Дети разговаривают с ним,
> он отвечает голосом, ездит, реагирует. Строим вместе с детьми.

---

## Идея

Колёсная платформа + микрофон + динамик + экранчик + Claude API.
Ребёнок задаёт вопрос голосом — робот думает и отвечает вслух.
Может ездить, показывать картинки, рассказывать истории.

**Почему это круто:**
- Дети получают доступ к AI в физическом и безопасном формате
- Строим вместе — они видят как это работает изнутри
- Реальный проект с реальным результатом

---

## Фазы проекта

### Фаза 1 — Базовый робот (1–2 недели после отпуска)
- [ ] Собрать колёсную платформу с Arduino
- [ ] Добавить ультразвуковой датчик — объезжает препятствия
- [ ] Проверить что ездит и не врезается

**Компоненты:**
- Колёсное шасси (~400 руб)
- Arduino Uno (уже есть)
- Драйвер моторов L298N (~200 руб)
- HC-SR04 датчик (~150 руб)

### Фаза 2 — Мозг (2–3 недели)
- [ ] Добавить Raspberry Pi 4 как основной мозг
- [ ] Подключить микрофон USB
- [ ] Подключить маленький динамик
- [ ] Распознавание речи (Whisper от OpenAI — бесплатно локально)
- [ ] Интеграция Claude API — отвечает на вопросы текстом

**Компоненты:**
- Raspberry Pi 4 (2–4GB) (~4000 руб)
- USB микрофон (~500 руб)
- Мини-динамик с усилителем (~300 руб)

### Фаза 3 — Голос и лицо (2 недели)
- [ ] Text-to-speech — робот говорит вслух (pyttsx3 или ElevenLabs)
- [ ] Маленький экран 3.5" — показывает эмоции/картинки
- [ ] Придумать имя и характер вместе с детьми
- [ ] Корпус — распечатать на 3D принтере или сделать из коробки

### Фаза 4 — Функции для детей (по желанию)
- [ ] Рассказывает истории по запросу
- [ ] Задаёт детям загадки и викторины
- [ ] Реагирует на имя (wake word)
- [ ] Родительский контроль — фильтр тем

## Стек технологий

| Слой | Технология |
|------|-----------|
| Движение | Arduino + L298N |
| Мозг | Raspberry Pi 4 |
| Речь → текст | OpenAI Whisper (локально) |
| AI ответы | Claude API (claude-haiku-4-5 — быстрый и дешёвый) |
| Текст → речь | pyttsx3 или ElevenLabs |
| Экран | 3.5" TFT дисплей |
| Корпус | 3D печать или картон на старте |

## Как вести с детьми

- Фаза 1 собираем вместе — они держат детали, закручивают
- Фаза 3 они придумывают имя, характер, какие вопросы задавать
- Показывать как работает каждый шаг — не магия, а понятная система
- Старший (9 лет) может писать простые команды на Python
